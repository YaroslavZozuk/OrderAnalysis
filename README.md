<h1 align="center">Sales Analysis in Power BI</h1>

**English**

An educational sales analysis project built using data from an Excel file. The result is an interactive Power BI dashboard for tracking sales and profit, comparing product categories and states, and exploring performance over time.

## Project Objective
Turn Excel data into a clear report and answer the following questions:
- What are the total sales, profit, and average sales value?
- How do sales vary by month and year?
- Which states generate the most sales?
- Which product categories contribute the most to sales?

## Data Source
The report uses data from an Excel file. The dashboard covers **2021–2024** and includes analysis by product category, region, and US state.

## Tools
- **Microsoft Excel** — source data file.
- **Microsoft Power BI Desktop** — report development, visualizations, and interactive filters.

## Dashboard Features
- KPI cards for total sales, order count, total profit, and average sales value.
- Monthly sales chart aggregated across the reporting period.
- Comparison of monthly sales across years.
- State ranking by sales.
- Sales comparison by product category.
- Matrix with annual metrics and overall totals.
- Filters for product categories, regions, and states.
- Consistent blue and white report design.

## Key Findings
- **Technology** generates the highest sales among the three product categories.
- **California** leads the state sales ranking, followed by **New York**.
- **2024** has the highest annual sales, at **733,215.26**.
- Sales increased from **470,532.51 in 2022** to **609,205.60 in 2023**, then to **733,215.26 in 2024**.
- In the aggregated monthly chart, **November** has the highest sales and **February** the lowest. This observation describes the reporting period; further analysis is needed to establish a consistent seasonal pattern.

## How to View the Project
1. Download the `.pbix` report file from this repository.
2. Open it in Microsoft Power BI Desktop.
3. Use the category, region, and state filters to explore individual segments.
4. To refresh the Excel data, update the source file path in the data source settings.
Power BI Desktop is required to explore the interactive report. GitHub does not display `.pbix` files as interactive dashboards.

## Skills Demonstrated
- Working with Excel data in Power BI.
- Building an interactive dashboard.
- Selecting visualizations for comparisons and time-based analysis.
- Configuring filters and report formatting.
- Drawing conclusions from visualized data.

## Author
Educational project for a Junior Data Analyst portfolio.


<h1 align="center">Аналіз продажів у Power BI</h1>

**Українська**

Аналіз продажів у Power BI
Навчальний проєкт з аналізу продажів на основі даних з Excel. Результат — інтерактивний дашборд у Power BI, який допомагає оцінювати продажі та прибуток, порівнювати категорії товарів і штати та відстежувати зміни показників у часі.

## Мета проєкту
Перетворити табличні дані з Excel на зрозумілий звіт і відповісти на запитання:
- Які загальні продажі, прибуток та середнє значення продажів?
- Як змінюються продажі за місяцями та роками?
- Які штати мають найбільші продажі?
- Які категорії товарів формують найбільший обсяг продажів?

## Джерело даних
Джерелом був файл Excel, дані якого використано для створення звіту в Power BI. Дашборд охоплює період **2021–2024 років** і містить аналіз за категоріями товарів, регіонами та штатами США.

## Інструменти
- **Microsoft Excel** — вихідний файл з даними.
- **Microsoft Power BI Desktop** — створення звіту, візуалізацій та інтерактивних фільтрів.

## Що реалізовано
- Картки основних показників: сума продажів, кількість замовлень, сума прибутку та середнє значення продажів.
- Графік продажів за місяцями за весь період.
- Порівняння місячних продажів між роками.
- Рейтинг штатів за обсягом продажів.
- Порівняння продажів за категоріями товарів.
- Матриця з річними показниками та загальними підсумками.
- Фільтри за категоріями товарів, регіонами та штатами.
- Узгоджене оформлення звіту в синьо-білій палітрі.

## Висновки
- **Technology** має найбільший обсяг продажів серед трьох категорій.
- **California** лідирує за продажами серед штатів; наступним у рейтингу є **New York**.
- **2024 рік** має найбільшу річну суму продажів — **733 215,26**.
- Продажі зросли з **470 532,51 у 2022 році** до **609 205,60 у 2023 році**, а потім до **733 215,26 у 2024 році**.
- На сукупному графіку за місяцями найбільші продажі припадають на **листопад**, найменші — на **лютий**. Це спостереження за наведеним періодом; для підтвердження стійкої сезонності потрібен окремий аналіз.

## Як переглянути проєкт
1. Завантажте файл звіту з розширенням `.pbix` із цього репозиторію.
2. Відкрийте його в Microsoft Power BI Desktop.
3. Використовуйте фільтри категорій, регіонів і штатів, щоб дослідити окремі сегменти.
4. Якщо потрібно оновити дані з Excel, у налаштуваннях джерела даних укажіть шлях до відповідного локального файлу.
Для перегляду інтерактивного звіту потрібен Power BI Desktop: GitHub не відображає файл `.pbix` як інтерактивний дашборд.

## Навички, продемонстровані в проєкті

- Побудова інтерактивного дашборда.
- Вибір візуалізацій для порівняння показників і аналізу динаміки.
- Налаштування фільтрів та оформлення звіту.
- Формулювання висновків на основі візуалізованих даних.
